# The AI Industry, End to End

A single-file interactive reference on the AI industry: who makes what, who pays whom, how the technology works, and where the money pools. State of play: July 2026.

Open `index.html` in any browser (fully self-contained, no dependencies), or view the published page via GitHub Pages.

Built from primary sources (company filings, the Dwarkesh Podcast Dario Amodei interview, SemiAnalysis reporting) with all time-sensitive figures carrying as-of dates. See the Glossary & sources tab inside the page.
